# 🌱 RiegoTEC Dashboard

A full-stack IoT web application for monitoring and controlling a smart irrigation system in real time.

## Overview

RiegoTEC is a web platform developed with React and Firebase that allows users to visualize environmental sensor data, configure automatic irrigation rules, and monitor crop conditions through an intuitive dashboard.

## Features

- User authentication
- Real-time sensor monitoring
- Temperature, humidity and light visualization
- Automatic irrigation configuration
- Interactive charts using Recharts
- Firebase Realtime Database integration

## Technologies

- React
- JavaScript (ES6)
- Firebase Authentication
- Firebase Realtime Database
- Recharts
- CSS

## Architecture

ESP32 Sensors → Firebase Realtime Database → React Dashboard
